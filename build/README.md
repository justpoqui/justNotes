# App icon

- `icon-source.png` — the original artwork (2000×2000).
- `icon.png` — the app icon (1024×1024, transparent corners), used for the window,
  the app menu entry and the installers (`npm run package`).

To change the icon, replace `icon.png` with a square PNG (512×512 or larger,
transparent background) and run `npm run package` again.
