justNotes 1.0: the first full release.

A local-first notebook for Linux. Notes are plain Markdown files in your Documents folder, organized as Notebook → Section → Page. No account, no cloud.

**Writing**
- Block editor with headings, lists, to-dos, tables, code, quotes, pictures and links; type / for the block menu.
- Office-style ribbon: fonts, sizes, colors, highlights, alignment, styles, Find & Replace.
- Table and Picture tabs appear when you're in a table or on a picture (rows/columns, picture size and position).
- Offline spell-check (US/UK), AutoCorrect, AutoFormat, and Ctrl+Z to undo any automatic change.
- Insert date & time; word-by-word undo; pages save by themselves.

**Organizing**
- Colored section tabs, pages in the sidebar, subpages (two levels, foldable), drag to reorder.
- Ctrl+P to jump to any page; Recent and Favorites; page title renames the page.
- A whiteboard on every page.

**Safety**
- Recycle bin (30 days), page history with "Save a version now", backups and automatic daily backups.

**Updates**
- From now on, new versions appear as "Update pending" in the app. Click it, then Install and restart.
